# racabugida-front

A modern, beautiful, and optimized frontend for the Rotaract Club of Abugida.

## Features
- React 19 + TypeScript
- Tailwind CSS with custom club color palette
- Responsive, accessible, and mobile-first design
- Modern navigation, hero, and footer
- Animated statistics, project/news/event cards
- Gallery with lightbox and filters
- Contact form with validation and EmailJS
- Toast notifications (react-toastify)
- Framer Motion & AOS for animations
- SEO meta tags (React Helmet)
- Code splitting, lazy loading, and performance optimizations
- 404 and error pages

## Stack
- React 19
- TypeScript
- Tailwind CSS
- React Router
- React Hook Form + Yup
- Framer Motion, AOS
- React Toastify
- EmailJS
- React Helmet

## Getting Started

1. **Install dependencies:**
   ```bash
   npm install
   ```
2. **Start the dev server:**
   ```bash
   npm run dev
   ```
3. **Build for production:**
   ```bash
   npm run build
   ```

## Customization
- Update `tailwind.config.js` for your color palette.
- Edit `src/pages` and `src/components` for your content.
- Configure EmailJS in the contact form.
